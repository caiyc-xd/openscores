公开版权（CC0 / 公共领域）乐谱的网页渲染与试听。基于 alphaTab 开源引擎，可在线看谱、听谱。

项目说明

  • 所有谱面排版（engraving）按 CC0-1.0 献出；原作本身已过版权保护期（作曲家去世 ≥ 70 年）。
  • 渲染引擎 alphaTab（MPL-2.0，官方发布构建未修改）、制谱字体 Bravura（SIL OFL 1.1）、合成音色 FluidR3 GM（MIT），许可全文见 licenses/。
  • 本仓库为开放项目，欢迎通过 Issues / Pull Requests 完善曲库与播放器。
  • 独立项目：与 MuseScore / IMSLP 的 OpenScore 计划同名但没有任何隶属、赞助或合作关系。

本地运行

python3 -m http.server 8080
# 浏览器打开 http://localhost:8080/player.html?score=scores/...

提示：请用本地 http 服务器打开，而非 file:// 直接双击，否则浏览器会禁止读取本地谱文件。
